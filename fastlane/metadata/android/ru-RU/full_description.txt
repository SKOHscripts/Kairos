Kairos подсказывает, что делать сейчас. Он расставляет задачи в порядке выполнения, вписывает их в свободное время между встречами, узнаёт, сколько они длятся на самом деле, и помогает закрепить привычки. Вы фиксируете, Kairos решает. Без аккаунта и рекламы: данные остаются на Вашем устройстве.

<b>Коротко</b>
<ul>
<li><b>Список, который сортируется сам</b>: задача на сейчас наверху, и Kairos объясняет почему.</li>
<li><b>День, который выдерживает</b>: задачи вокруг встреч, защищённое время для глубокой работы, лёгкие дела в послеобеденный спад.</li>
<li><b>Привычки, которые закрепляются</b>: постоянное время, фраза «После…», проверенный вопрос, научные источники.</li>
<li><b>Всё более точные оценки</b>: машинное обучение на устройстве узнаёт реальное время задач.</li>
<li><b>Реально потраченное время</b>: секундомер для каждой задачи, предупреждения и честная статистика.</li>
<li><b>Ваши данные у Вас</b>: без аккаунта, без трекеров, по умолчанию офлайн.</li>
</ul>

<b>Порядок, который объясняется</b>
Каждая задача получает оценку приоритета (WSJF): её ценность (приоритет P0, P1 или P2 плюс срочность срока) делится на трудоёмкость в очках. Маленькое и важное идёт раньше большого и далёкого; просроченная задача всегда первая. «Почему на этом месте?» показывает расчёт одним касанием.

<b>Реалистичный день</b>
Фиксированное время, повторяющиеся задачи (ежедневно, по будням, еженедельно, «23-го числа»), зависимости, подзадачи, праздники 13 стран. Карточка «Твой день» сводит задачи, сроки, реальную доступность и глубокую работу.

<b>Привычки на научной основе</b>
Повторяющуюся задачу можно сделать привычкой. Kairos предлагает время, когда она уже выполняется, и затем никогда его не сдвигает: именно устойчивый сигнал формирует автоматизм. Фраза «После утреннего кофе» привязывает её к распорядку. Время от времени при отметке проверенный вопрос уточняет, делается ли это автоматически, а кривая показывает прогресс. Никаких серий, вызывающих чувство вины: один пропуск не считается. У каждого утверждения есть источник — в приложении и на сайте.

<b>Машинное обучение на устройстве, а не ИИ</b>
Модель, обученная на Вашем устройстве, оценивает длительность новой задачи по похожим выполненным задачам, с диапазоном. Kairos применяет её, только если она точнее длительности по умолчанию на Вашей истории. Ни чат-бота, ни облака.

<b>Фиксировать без усилий (GTD)</b>
Идея? Заметка. Задача? Достаточно названия: она ждёт во «Входящих» приоритета и размера, по одному касанию.

<b>Реальное время</b>
Секундомер для каждой задачи с уведомлением; предупреждения о превышении, забытом секундомере и перерыве, даже при закрытом приложении. При отметке Kairos спрашивает потраченное время; отвлечения отмечаются задним числом.

<b>Команда (по желанию)</b>
Второе пространство для руководителя, единственного пользователя: участники, бэклог, загрузка каждого, прогнозы Монте-Карло и обмен файлами с участниками.

<b>Ваши данные остаются у Вас</b>
Без аккаунта, рекламы и трекеров. Экспорт JSON, актуальная копия в синхронизируемой папке, календари .ics, ICS или CalDAV только для чтения. Сеть нужна лишь для необязательных онлайн-подключений, выключенных по умолчанию.

Также для Windows, Linux, macOS и браузера, в стиле Material или «Cadran». Свободное ПО (GNU AGPL v3 или новее), на русском, английском, французском, испанском, немецком и итальянском.
