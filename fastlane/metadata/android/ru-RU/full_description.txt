Kairos выстраивает ваши задачи в порядке выполнения и распределяет их по слотам работы и просто в свободное время в течение дня.

<b>Прозрачный приоритет задачи</b>
Каждой задаче присваивается приоритет по WSJF: её ценность (приоритет P0, P1 или P2 плюс срочность срока) делится на оценку трудоёмкости в баллах. Мелким и важные задачи получают первенство по отношению к крупным и неважным; просроченная задача всегда ставиться вперёд. Блок «Почему это место?» в задаче в одно касание отображает логику подсчёта и причину конкретной позиции в очереди.

<b>Реалистичный день</b>
<ul>
<li>Расписание учитывает ваши блоки занятости (обязательные встречи, другие дела) и вставляет настраиваемые промежутки после них.</li>
<li>Интервалы (блоки) deep work защищены; во второй половине дня сложные задачи уступают место более легким.</li>
<li>Поддерживаются: фиксированное время для задачи, повторяющиеся задачи (ежедневно, по будням, еженедельно, «23-го числа каждого месяца»), зависимости между задачами, редактируемые подзадачи, официальные праздники Франции.</li>
</ul>

<b>Быстрая запись без лишних усилий (GTD)</b>
Идея? Заметка. Задача? Достаточно названия: она остаётся в разделе «К обработке», пока вы не укажете приоритет и размер — по одному касанию на каждую.

<b>Оценка временных затрат</b>
Таймер для каждой задачи с постоянным уведомлением; напоминания по превышению времени выделенного на задачу, напоминание о пропущенном таймере и об отдыхе, даже при закрытом приложении. Статистика сравнивает ваши оценки с фактически затраченным временем и становиться точнее со временем. Так вы можете выставить трудоёмкость задачи и сразу получить примерную оценку времени на её выполнение.

<b>Управление командой (необязательно)</b>
По умолчанию выключено: управление командой добавляет второе пространство для руководителя, который остаётся единственным его пользователем:
<ul>
<li>Участники и отсутствия, общий бэклог, ход выполнения работ с журналом изменений.</li>
<li>Загрузка каждого человека относительно его доступного времени и предложенное распределение задач; ваши личные задачи могут учитываться в вашей загрузке.</li>
<li>Прогнозы Monte Carlo: даты завершения в виде вероятности в процентах, какие сроки под угрозой, сценарии «Что если…?».</li>
<li>Обмен файлами с участниками, которые пользуются Kairos: они получают свои задачи и возвращают статус выполнения.</li>
<li>Всё остаётся на устройстве; в личном пространстве никогда не отображается ничего из командного.</li>
</ul>

<b>Ваши данные остаются у вас</b>
<ul>
<li>Без аккаунта, без рекламы, без трекеров, без разрешения на доступ к сети.</li>
<li>Резервное копирование и лёгкое распространение в формате JSON.</li>
<li>Встречи из файла календаря (.ics: Outlook, Google, Thunderbird) или, по желанию, из календарей вашего телефона: тогда Kairos запросит доступ к календарю только для чтения и по-прежнему никогда не будет подключаеться к сети.</li>
</ul>

Kairos также доступен для Windows, Linux, macOS и в браузере. Это свободное программное обеспечение распространяемое под лицензией MIT с интерфейсом на английском, французском, испанском, немецком, русском и итальянском языках (выбор в настройках; по умолчанию — язык вашей системы, если он есть в этом списке, иначе английский).
