Todo-инструменты ведут список, но не сортируют его. Kairos объединяет agile, todo и GTD в список, который развивается сам и подсказывает, что делать сейчас: доверьтесь ему, разгрузите голову. Он учится на устройстве оценивать время: чем чаще пользуетесь, тем точнее.

<b>Машинное обучение на устройстве</b>
Модель машинного обучения, обученная на устройстве, даёт задаче с новым названием длительность по похожим выполненным задачам, с диапазоном и их списком. Kairos применяет её, только если на вашей истории она точнее длительности по умолчанию, учит ваш ритм по дням и часам и сообщает об изменении оценок. ИИ? Нет, надёжное локальное машинное обучение без чат-бота и облака, которое обучается на каждой выполненной задаче.

<b>Прозрачный приоритет задачи</b>
Каждой задаче присваивается приоритет по WSJF: её ценность (приоритет P0, P1 или P2 плюс срочность срока) делится на оценку трудоёмкости в баллах. Мелким и важные задачи получают первенство по отношению к крупным и неважным; просроченная задача всегда ставиться вперёд. Блок «Почему это место?» в задаче в одно касание отображает логику подсчёта и причину конкретной позиции в очереди.

<b>Реалистичный день</b>
<ul>
<li>Расписание учитывает ваши блоки занятости (обязательные встречи, другие дела) и вставляет настраиваемые промежутки после них.</li>
<li>Интервалы (блоки) deep work защищены; во второй половине дня сложные задачи уступают место более легким.</li>
<li>Поддерживаются: фиксированное время для задачи, повторяющиеся задачи (ежедневно, по будням, еженедельно, «23-го числа каждого месяца»), зависимости между задачами, редактируемые подзадачи, праздники 13 стран.</li>
<li>Карточка «Твой день»: задачи, сроки, deep work.</li>
</ul>

<b>Быстрая запись без лишних усилий (GTD)</b>
Идея? Заметка. Задача? Достаточно названия: она остаётся в разделе «К обработке», пока вы не укажете приоритет и размер — по одному касанию на каждую.

<b>Оценка временных затрат</b>
Таймер для каждой задачи с постоянным уведомлением; напоминания по превышению времени выделенного на задачу, напоминание о пропущенном таймере и об отдыхе, даже при закрытом приложении. При отметке задачи Kairos спрашивает затраченное время; прерывания отмечаются постфактум. Статистика сравнивает оценки с фактическим временем и становится точнее.

<b>Управление командой (необязательно)</b>
По умолчанию выключено: управление командой добавляет второе пространство для руководителя, который остаётся единственным его пользователем:
<ul>
<li>Участники и отсутствия, общий бэклог, ход выполнения работ с журналом изменений; личное пространство этого не показывает.</li>
<li>Загрузка каждого человека относительно его доступного времени и предложенное распределение; ваши личные задачи могут учитываться.</li>
<li>Прогнозы Monte Carlo: даты завершения в виде вероятности в процентах, какие сроки под угрозой, сценарии «Что если…?».</li>
<li>Обмен файлами с участниками, которые пользуются Kairos: они получают свои задачи и возвращают статус выполнения.</li>
</ul>

<b>Ваши данные остаются у вас</b>
<ul>
<li>Без аккаунта, без рекламы, без трекеров. Сеть нужна только необязательным онлайн-подключениям (по умолчанию выключены).</li>
<li>Резервное копирование и лёгкое распространение в формате JSON; либо актуальная копия в синхронизируемой папке.</li>
<li>Встречи из файла календаря (.ics: Outlook, Google, Thunderbird), по ссылке ICS, с сервера CalDAV или, по желанию, из календарей телефона, только для чтения: тогда Kairos запросит доступ к календарю. Импорт файла никогда не использует сеть.</li>
</ul>

Kairos также доступен для Windows, Linux, macOS и в браузере, в стиле Material или «Cadran». Это свободное программное обеспечение под лицензией GNU AGPL v3 или новее, с интерфейсом на английском, французском, испанском, немецком, русском и итальянском языках (выбор в настройках; иначе язык системы или английский).
